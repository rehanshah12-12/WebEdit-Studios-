# WebEdit Studio
Full-stack Node.js + Express + PostgreSQL website.

## Setup
1. Copy `.env.example` to `.env`.
2. Add your PostgreSQL `DATABASE_URL` and a strong `SESSION_SECRET`.
3. Run `npm install`.
4. Run `database/schema.sql` on PostgreSQL.
5. Run `npm start`.

Never upload `.env` or real database credentials to GitHub.
